# Casino Bot

Telegram casino: Мины, Башня, Пирамида + CryptoBot.

## Bothost

Переменные:
```
BOT_TOKEN=
OWNER_ID=
CRYPTO_PAY_TOKEN=
CRYPTO_ASSET=USDT
MIN_BET=0.1
MIN_DEPOSIT=0.1
MIN_WITHDRAW=0.1
```

Команда: `python bot.py`

## Команды владельца
- `/addpartner ID`
- `/give ID сумма` — временный баланс на 1 час

## Игры
- Мины 5x5 (тайные мины, анти-абуз)
- Башня 5 уровней
- Пирамида 5 уровней
